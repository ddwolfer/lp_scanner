# Uniswap v3 Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 掃描器與頭寸追蹤同時支援 Uniswap v3 的「股票 × USDG」池（實測 280 個，185 個為 1% 費率），與 v4 池放在同一個排名比較。

**Architecture:** 新增 `sources/uniswapV3.ts`（Factory `PoolCreated` 發現、池合約 `Swap` / `Mint` / `Burn` log、`slot0`）。v3 `Swap` 事件沒有 fee 欄位，由 `pools.fee_ppm` 填入，讓 `aggregateHourly` 與模擬引擎完全共用。`pools.pool_id` 對 v3 是池合約地址（SPEC §6），DexScreener 的 pairId 也是池地址，TVL 對應不變。頭寸：`sources/positions.ts` 加 `fetchV3Positions`（NonfungiblePositionManager `tokenOfOwnerByIndex` / `positions()`，未領費用以 `collect` 的 eth_call 模擬取得），`syncPositions` 以 `notes.protocol` 區分。

**Spec:** SPEC §6 `pools.protocol`、§11.4 v3 地址（DECISIONS 11.4）、DECISIONS D15（本計畫推翻）、D29。

## Global Constraints
- v3 Factory `0x1f7d7550b1b028f7571e69a784071f0205fd2efa`、NPM `0x73991a25c818bf1f1128deaab1492d45638de0d3`。
- 只讀。`collect` 只用 `eth_call` 模擬，不送交易。
- 排除規則、模擬、評分對 v3 不變；v3 無 hooks（`hooks` 存零地址）、費率固定。

## Tasks
1. **`sources/uniswapV3.ts`**：`discoverV3UsdgPools(rpc, from, to): DiscoveredPool[]`（`protocol: 'v3'`, `poolId` = 池地址 lowercase, `hooks` = zero, `tickSpacing` from event）；`fetchV3Swaps(rpc, pool, feePpm, from, to): SwapLog[]`（sender = event sender；amount0/1 int256；fee = feePpm）；`fetchV3LiquidityEvents(rpc, pool, from, to): { txHash; sender }[]`（Mint 與 Burn）。測試：decode 純函式。
2. **`DiscoveredPool` 加 `protocol`**；`upsertPools` 寫入 `protocol`；`steps.isStockUsdgPool` 不變。
3. **run.ts**：發現階段同時跑 v3/v4；每池依 `p.protocol` 選 `fetchSwaps` 或 `fetchV3Swaps`；刷量階段 LP 地址依 protocol 取 `fetchModifyLiquidity` 或 `fetchV3LiquidityEvents`。摘要 label 用 `p.protocol`。
4. **backfill**：`scripts/backfill-pools.ts` 加 v3（PoolCreated 對 USDG 精確 topic 過濾可一次查全鏈，實測 4,548 筆一次回）。
5. **positions**：`fetchV3Positions(rpc, owner)`；`OnchainPosition` 加 `protocol`；`syncPositions` 的 `notes` 記 `protocol`；`fetchMintInfo` 的收款方改為「PoolManager 或該 v3 池地址」；`runPositionsStage` 合併 v3+v4。測試：v3 position 走 sync。
6. DECISIONS D34（推翻 D15）、README、跑 backfill v3、跑 `pnpm positions`、`pnpm scan --sim-only` 驗證、合併推送。
